产品经理视角

核心闭环
Discovery → Identification → Confirmation → Delivery → Reuse

产品解决什么

  • 老旧设备 / 工程资料不完整条件下的少量高价值点表发现。
  • Candidate + Confidence + Evidence + Engineer Decision 的可追溯确认。
  • 代表机深度分析 + 同类设备快速验证 + Exception 回退。
  • Device Knowledge Base 形成可复用实施资产。

明确不是

  • 不是 OT 安全平台。
  • 不是通用 OPC Server。
  • 不是 PLC 密码/程序破解工具。
  • 不是通用抓包器。
